# 2026-06-10 — Bootstrap `.harness/` for Unpostpone

Initial scaffold of the project team. **No production code changed.**

## Added

- `.harness/agent.md` — orchestrator (Harness) system prompt.
- `.harness/AGENTS.md` — project-wide index of standing rules and
  topic docs.
- `.harness/reins/android-developer/agent.md` — generalist
  Android developer (UI, data, domain, DI, navigation).
- `.harness/reins/tester/agent.md` — test owner (JVM unit +
  instrumented).
- `.harness/reins/blocker-expert/agent.md` — domain specialist for
  the AccessibilityService + temporary-unlock + Blocker/ReBlock/
  FocusReminder screens.
- `.harness/reins/pomodoro-expert/agent.md` — domain specialist
  for the Pomodoro timer (AlarmManager, USE_EXACT_ALARM, session
  state machine, Pomodoro screen).
- `.harness/docs/code-standards.md` — package layout, naming,
  Compose / Hilt / coroutines conventions.
- `.harness/docs/test-policy.md` — what to test, where, with
  which tools, and what NOT to test.
- `.harness/docs/build-policy.md` — version catalog, SDK levels,
  build types, build commands.
- `.harness/memory/MEMORY.md` — empty placeholder, to be populated
  as the team accumulates project-wide lessons.

## Decisions

- **5 agents total** (1 orchestrator + 4 reins). Skipped
  `code-reviewer` (no CI / no PR workflow yet) and skipped
  layer-split reins (`ui-expert` / `data-expert`) — clean
  architecture already separates those concerns.
- **One `android-developer`** owns UI + data + domain + DI +
  navigation. Blocked from touching the AccessibilityService
  internals and Pomodoro service internals (those are specialist
  territory).
- **`blocker-expert`** and **`pomodoro-expert`** exist because
  those two subsystems interact with Android system services in
  ways that have real correctness implications (Doze, exact
  alarms, accessibility events, foreground service type rules).
- **No hooks or crons yet.** Will add if/when the user asks
  (e.g. a "do not commit without running tests" hook).

## Follow-ups for the user

- [ ] Commit `.harness/` once reviewed. (Don't auto-commit; the
      orchestrator will commit on your signal.)
- [ ] Decide whether to add `.github/workflows/` for CI (then add
      a `code-reviewer` rein).
- [ ] Decide whether to replace the placeholder
      `ExampleUnitTest` / `ExampleInstrumentedTest` with real
      coverage now or after the first feature lands.
- [ ] Confirm the on-device test plan the blocker-expert and
      pomodoro-expert will hand back to you is acceptable (they
      never run `./gradlew` themselves).

# 2026-06-10 — `pomodoro-ui-redesign`

## Pomodoro screen — visual + structural redesign

Restructured the hero card into four explicit zones
(Context → Timer → Controls → Stat line). The "Reset"/"Cancel" link
no longer overlaps the 240dp ring, the session chip is now visible
(was an invisible `Surface` with `containerColor = surface` and
`border = null`), the eyebrow above the ring number is rendered
again, the primary action button is unified to `primary` across
Idle / Running / Paused / Finished, and the preset chips get a
check icon and a cycle-duration badge so the active preset reads
differently from the primary button.

### Touched files (7 total)

- `app/src/main/java/com/unpostpone/app/presentation/pomodoro/PomodoroScreen.kt`
- `app/src/main/java/com/unpostpone/app/presentation/pomodoro/components/PomodoroControls.kt`
- `app/src/main/java/com/unpostpone/app/presentation/pomodoro/components/PomodoroPresetChip.kt`
- `app/src/main/java/com/unpostpone/app/presentation/pomodoro/components/PomodoroTimerRing.kt`
- `app/src/main/java/com/unpostpone/app/ui/theme/Dimens.kt` — new
  tokens: `SessionChipMinWidth`, `PresetChipMinWidth`,
  `PresetFlowSpacing`, `HeroZoneSpacing`, `ControlsLinkSpacing`,
  `FocusRingTickRadius`, `HeroBorderWidth`,
  `PresetChipBorderWidth`, `SurfaceFlatElevation` (the last four
  are explicit-named `0.dp` / `1.dp` / `4.dp` values used in the
  Pomodoro composables so no `.dp` literal survives in the screen
  or its three components).
- `app/src/main/res/values/strings.xml` and

- `service/pomodoro/**`
